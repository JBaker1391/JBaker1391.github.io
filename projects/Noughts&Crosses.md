The goal of this project is to provide a console based environment for two individuals to play a round-based tic-tac-toe tournament. This application is coded in C# and provides a full tic-tac-toe experience to the player including an updating game board and scoring capabilities. The game runs as long as the users choose to continue playing, utilizes input validation to ensure no overlapping moves occur, and keeps tally of the number of wins per player to display an overall tournament champion upon completion.
